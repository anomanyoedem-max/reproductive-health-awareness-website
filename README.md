# Reproductive Health Awareness Website

A responsive static educational website about PCOS / PMOS and endometriosis, built with plain HTML, CSS, and JavaScript.

## Pages
- Home (`index.html`)
- PCOS / PMOS (`pcos.html`)
- Endometriosis (`endometriosis.html`)
- Symptoms (`symptoms.html`)
- Compare (`comparison.html`)
- Symptom Awareness (`awareness.html`)
- FAQ (`faq.html`)
- Resources (`resources.html`)

## Run locally
Open `index.html` in a web browser. No build tools or server are required.

## Publish on GitHub Pages
1. Create a GitHub repository and upload all files/folders to the repository root.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
4. Wait for GitHub Pages to publish the site.

## Features
- Responsive layout for desktop and mobile
- Mobile navigation menu and FAQ accordion
- Symptom awareness and comparison pages
- External health-resource links
- No external CSS or JavaScript dependencies

## Health notice
This website is for education and awareness only. It does not provide diagnosis or replace professional medical advice, diagnosis, or treatment. Seek qualified healthcare advice for persistent, severe, recurrent, or concerning symptoms.

Content is based on the user-provided document “PCOS and ENDOMETRIOSIS.” Check current guidance from recognized medical organizations before public clinical use.
